I'm a TypeScript enthusiast with over 10 years of experience in React. I'm all about creating great DevEx without compromising on UX. One way to do that is to avoid sending a 20-megabyte React SPA to people with an average mobile phone on a poor internet connection. Having a good developer experience on a powerful MacBook Pro shouldn't result in a degraded user experience for the people visiting a website. I highly recommend Alex Russell's series <a href="https://infrequently.org/series/performance-inequality/" target="_blank">The Performance Inequality Gap</a> on the subject.

I'm having fun <a href="https://codeberg.org/100terres/selfhost" target="_blank">self-hosting tools and services</a> on my homelab. My current side projects' tech stack includes: TypeScript, Astro, Docker, Pangolin, Dagu, and Codeberg. I would like to eventually migrate my Docker setup to Kubernetes, we'll see if I find the time for this!

I also maintain <a href="https://github.com/hello-pangea/dnd" target="_blank">@hello-pangea/dnd</a>, an open source project I created by forking Atlassian's react-beautiful-dnd, and it now has 3,000,000+ weekly downloads on NPM. You can read more about my motivations behind <a href="https://dev.to/100terres/rbd-is-dead-long-life-rfd-1n9e" target="_blank">this adventure here</a>.
